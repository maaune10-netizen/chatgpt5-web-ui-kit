# استكشاف الروابط — جرد المسارات الفعليّة

## لماذا ملفّ لا زحف

`chatgpt.com` · `help.openai.com` · `openai.com` كلّها **HTTP 403** من Cloudflare
(قيست بطلب واحد عاديّ لكلٍّ منها). ولا نتجاوز الحجب. فالمصدر هو **ملفّ من
المستخدم**: تصدير سجلّ، إشارات مرجعية، أو قائمة يدويّة.

## كيف يُحوَّل

```bash
node tools/links.mjs <ملفّك>          # جدول في الطرفية
node tools/links.mjs <ملفّك> --md     # جدول Markdown جاهز للّصق هنا
node tools/links.mjs <ملفّك> --json   # ملفّ للتوثيق
```

يقبل أي نصّ: سطر لكل رابط، أو JSON، أو HTML. ويستخرج كل `http(s)://…`، ثم:

- **يطبّع المعرّفات** — `/c/68f3a2b1-…` و`/c/71aa99cc-…` يصيران `/c/:id`.
- **يعدّ** — عشرون رابطًا إلى نفس المسار تعني مسارًا واحدًا، لا عشرين صفحة.
- **يميّز النطاقات** — `chatgpt.com` عن `help.openai.com`.

## ما نعرفه أصلًا — من الـKit

| المسار | الحالة |
|---|---|
| `/` | ✅ |
| `/c/:id` | ✅ |
| `/library` | ✅ |
| `/project/:id` | ✅ |
| `/project/:id/c/:id` | ✅ |

## ما يقرّره ملفّك — الأسئلة الخمسة

1. **هل يظهر `/g/…` إطلاقًا؟** إن غاب فهو **دليل** على أنّ عائلة GPTs أُزيلت،
   لا مجرّد كلام منقول. وإن ظهر، فعندنا ما نناقشه.
2. **ما مسارات المصادقة؟** `/auth/login`؟ `/auth/signup`؟ مسار واحد أم اثنان؟
   وهل هناك `/auth/verify` أو `/auth/reset`؟
3. **كم مسارًا تحت `/settings/`؟** عندنا صفحة إعدادات واحدة؛ والموقع الحقيقي قد
   يكون له عشرة. وهذا يغيّر حجم العمل كثيرًا.
4. **هل `/share/:id` مسار مستقلّ أم نافذة؟** عندنا نافذة.
5. **ما المسارات التي لم نتوقّعها؟** هي أثمن ما في الملفّ — كل ما ليس في جدولنا.
